# Status report

```yaml
slug: status-report
title: Delivery status report
aliases: [weekly-status, project-status, steering-update]
example: examples/status-report.html
command: /document-design-system:status-report
pattern: brief
default-theme: executive-navy
default-format: markdown
path: docs/status/
```

**Reader's question:** where are we now, what changed, and what needs attention?

Lead with period, overall health in words, forecast, and decision needs. Then
cover outcomes completed, plan versus actual, next period, risks/issues,
dependencies, changes, budget/effort only when evidenced, and owned actions.

Do not make a status report a diary or copy the full RAID register. Explain why
health changed and what the reader must do.

## Output

Markdown in `docs/status/`; pattern `brief`, theme `executive-navy`.
