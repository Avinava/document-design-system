Start from the reader's question

A pattern is how a page reads: where the answer sits, what repeats, and what the reader does last. Find the question your reader is asking. The pattern follows, and so do its presets — thirty-four of them across eleven patterns. If none of the presets fits, compose in that pattern.

The same catalog, by engagement stage

Each stage lists the documents that usually own its questions. Choose the smallest set the engagement needs.

  1. Frame and agree

    Why, scope, outcome, effort, commercial delivery boundary.

    • Discovery brief
    • Proposal
    • Basis of estimate
    • Project charter
    • Statement of work

  2. Define

    Observable need, target design, current system, decisions, interfaces, threats.

    • Requirements specification
    • Design doc
    • Architecture guide
    • Architecture decision record
    • Specification
    • API contract
    • Threat model

  3. Plan and govern

    Work, dependencies, quality, exposure, status, controlled change.

    • Delivery plan
    • Test strategy
    • Risk and RAID register
    • Delivery status report
    • Change request

  4. Verify and transition

    Readiness, test verdict, cutover, release impact, support and handoff.

    • Production readiness review
    • Test report
    • Migration and cutover plan
    • Release notes
    • Support model
    • Engineering handoff

  5. Operate and improve

    Find truth, execute safely, communicate incidents, learn.

    • Service documentation suite
    • Reference
    • How-to guide
    • Runbook
    • Incident update
    • Postmortem
    • Onboarding

Not listed?

Compose it. The writing skill does this when no preset fits, in three steps.

  1. Match a type or a familiar name

    If a preset or one of its names fits, use it. Composition is the fallback, not a second catalog.

  2. Pick the pattern by the reader's question

    The question table above names the pattern. The pattern fixes the reading order.

  3. Compose from the pattern's modules

    Use only the modules the pattern allows, and borrow the nearest preset's section discipline and theme.

A shape composed three times becomes a preset. That is the only way the catalog grows.
