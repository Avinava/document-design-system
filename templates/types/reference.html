Configuration keys

  • INGEST_QUEUE_URIRequiredCurrent queue endpoint; dispatcher URI after RFC 014Defaultnone
  • INGEST_GATEWAY_ADDROptionalBind addressDefault127.0.0.1:8443
  • INGEST_SHED_MSOptionalMaximum proposed dispatcher waitDefault200
  • INGEST_LOG_LEVELOptionaldebug, info, warn, or errorDefaultinfo

Process endpoints

GET

/health/live

Process is running. Does not prove queue access.

GET

/health/ready

Required configuration is present and the current queue is reachable.

GET

/metrics

Prometheus metrics including request count, enqueue latency, shed count, and errors.

Process exit codes

Stable exits used by deployment automation
CodeMeaningOperator response
0Clean shutdownNone
2Required configuration missingCheck INGEST_QUEUE_URI
3Bind failedCheck address and port ownership
4Queue unavailable during startupCheck dependency and readiness policy
