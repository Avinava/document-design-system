The parts a pattern is built from

A module is one class in core/document-patterns.css with one reading job. @@MODULES_WORD_CAP are registered. A page uses only the modules its pattern allows, which is what keeps a composed document reading like its pattern.

Each specimen below is lifted from an example that uses it and rendered with the real stylesheet. Specimens wear this page's theme; open the example to see each one in its own.

The registry is the Modules table in core/document-patterns.md. The validator fails when a registered class has no CSS, when CSS styles an unregistered class, or when a body uses a module its pattern does not allow.
